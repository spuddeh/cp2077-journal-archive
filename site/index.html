What this is

Every word of text in Cyberpunk 2077 as a queryable database: shards, phone conversations, codex entries, computer mail and files, the in-game internet, the quest log, the tarot readings, and all 104,895 lines of spoken dialogue with who says each one and to whom. English, base game and Phantom Liberty.

Each entry keeps the LocKeys its strings came from, which is what a mod needs to reference or override a line.

Using it

The search box is full text over titles and text. field:value narrows it - speaker:johnny addressee:alt, blackwall kind:shard - and a filter with no search words lists matching lines in scene order. Quote a phrase ("night city"), combine with OR, and quote any word holding punctuation.

An id in a result opens the whole record, a scene reads it back in order, and a speaker lists everything that character says. The address bar keeps the search, the query and the open record, so a link reproduces what is on screen.

The SQL tab reads the same database directly. entries holds one row per entry, with its full record as JSON in data; search is the FTS5 index over title and text. The query cookbook has the shapes that answer real questions, and the traps that make a wrong answer look like a right one.

The page queries a SQLite database over HTTP range requests, so only the parts a query touches are downloaded; the counter in the header shows how much. A query that has to read every row downloads most of the database, and a query that an index answers costs a few hundred kilobytes.

Where it comes from

The text is read from the game's journal resource, subtitle resources and scene files, and resolved against the English string tables. The extraction scripts and the archive as JSONL are in the repository this site is published from.
